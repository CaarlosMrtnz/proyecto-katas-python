# Katas en Python

En este repositorio recojo una colección de 40 ejercicios (katas) en Python realizados como parte de mi formación en el Máster en Ciberseguridad. Los he ido haciendo para asentar la base del lenguaje, practicar la sintaxis y resolver pequeños problemas concretos escribiendo código desde cero. 

## ⚖️ Filosofía del proyecto

El objetivo ha sido reforzar los fundamentos de Python de manera práctica y progresiva, centrándome en resolver los problemas apoyándome en las características nativas del lenguaje. Es una forma de interiorizar la lógica, entender bien las estructuras de datos y practicar conceptos como la programación funcional o la orientación a objetos antes de pasar a herramientas y entornos más complejos.

## ⚙️ Conceptos trabajados

Estos son los conceptos principales que he puesto en práctica:

* **Control de flujo:** Uso de condicionales (`if`, `elif`, `else`) y bucles (`for...in`, `range`) combinados con operadores lógicos para guiar la ejecución de los programas.
* **Estructuras de datos:** Manejo de listas (list comprehensions, añadir y eliminar elementos), diccionarios (acceso, actualización y conteo de frecuencias), tuplas y conjuntos (`set` para limpiar elementos repetidos).
* **Funciones:** Definición de funciones (`def`), uso de parámetros opcionales, argumentos variables (`*args`) y retornos.
* **Programación funcional:** Aplicación de funciones anónimas (`lambda`) junto con utilidades como `map()`, `filter()` y `reduce()` para procesar colecciones de datos.
* **Manipulación de cadenas:** Limpieza, validación y transformación de texto utilizando los métodos integrados (`split()`, `strip()`, `lower()`, `replace()`, `join()`, etc.).
* **Gestión de errores:** Uso de bloques `try-except` para controlar excepciones, validación de datos con `raise` y definición de clases de error propias.
* **Programación Orientada a Objetos (POO):** Creación de clases, uso del método `__init__`, atributos, métodos e interacción entre distintos objetos.
* **Entrada de datos y conversión de tipos:** Lectura de datos por consola con `input()` y conversión entre distintos tipos de datos.

## 📂 Organización del proyecto

El repositorio tiene una estructura totalmente plana. Está formado por 40 archivos independientes, uno por cada ejercicio.

```text
proyecto-katas-python/
  ─ ejercicio-01.py
  ─ ejercicio-02.py
  ─ ejercicio-03.py
  ...
  ─ ejercicio-40.py
```

Dentro de cada archivo se encuentra el enunciado del ejercicio comentado, seguido de la solución correspondiente.

## 💻 Ejecución local

Los ejercicios no requieren dependencias externas. Para revisar o ejecutarlos localmente:

1. Clona el repositorio:

   ```bash
   git clone https://github.com/CaarlosMrtnz/proyecto-katas-python.git
   ```

2. Accede al directorio:

   ```bash
   cd proyecto-katas-python
   ```

3. Ejecuta cualquier ejercicio con Python:

   ```bash
   python ejercicio-01.py
   ```
